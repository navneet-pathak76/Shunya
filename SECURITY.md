# Security

SUNYA is designed around sensitive personal and health-adjacent information.

## Rules

- Never commit API keys, tokens, passwords or private health exports.
- Use secure storage for device credentials and tokens.
- Minimize collection and retention of sensitive data.
- Gate device/health integrations behind explicit permissions.
- Log events without leaking sensitive payloads.
- Treat AI output as untrusted input and validate structured responses.
- Document threat models before enabling synchronization or remote AI processing.

## Reporting

For private development, security issues should be handled privately by the project owner rather than disclosed through public issues.
