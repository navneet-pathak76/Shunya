# SUNYA Domain Registry

The mobile client is organized around independent domains rather than a collection of unrelated pages.

Core domains: onboarding, dashboard, profile, body, measurements, weight, body composition, nutrition, meals, meal schedule, hydration, workouts, exercises, sleep, recovery, habits, smoking, alcohol, medications, supplements, mood, journal, goals, reminders, notifications, reports, analytics, AI, settings, privacy, security, integrations, health connectivity, wearables, camera, voice, backup, and export.

Each domain may contain screens, widgets, state providers, repositories, data models, services, validators, and tests as implementation begins.
