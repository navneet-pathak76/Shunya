# SUNYA Roadmap

## Phase 0 — Skeleton

- Repository structure
- Domain boundaries
- Documentation framework
- CI/CD placeholders
- Security baseline

## Phase 1 — Local-first foundation

- Flutter shell
- Navigation
- Design system
- Local database
- User profile
- Core body measurements

## Phase 2 — Tracking domains

- Weight and body composition
- Nutrition and meals
- Hydration
- Workouts and exercises
- Sleep and recovery
- Habits
- Smoking and alcohol
- Medication and supplements
- Mood and journal

## Phase 3 — Intelligence

- Personal analytics
- Goal engine
- AI context layer
- AI assistant
- Recommendations with provenance

## Phase 4 — Integrations

- Health Connect
- Wearables
- Camera
- Voice
- Import/export
- Backup/sync

## Phase 5 — Production

- Backend
- PostgreSQL
- Authentication if required
- Observability
- Automated testing
- Deployment

No phase should be considered complete until its security, privacy, testing and documentation requirements are defined.
