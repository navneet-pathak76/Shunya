# SUNYA Implementation Contract

This directory is the implementation boundary for the SUNYA mobile client.

Every feature follows the same intended lifecycle:

1. Product specification
2. Domain/data contract
3. UI/UX specification
4. Repository contract
5. State/provider contract
6. Screen and widget implementation
7. Persistence
8. Notifications/background work
9. Tests
10. Documentation and acceptance criteria

No feature should bypass the domain and privacy contracts merely to make a screen work.
